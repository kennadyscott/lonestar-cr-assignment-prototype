# LoneStar CR Assignment Prototype

Clickable prototype of the redesigned LoneStar CR constructed-response assignment:
four guided steps (Read, Highlight, Organize, Revise & Edit), grade-band switching
(2–3, 4–5, 6–8, 9–12), Luna writing supports, and a sample Extended Writing Feedback screen.

- Open `index.html` in a browser, or view it on GitHub Pages.
- Prototype only: demo writing, sample feedback, and all 4–5 / 6–8 / 9–12 scaffold
  wording marked as placeholder in the code are not final content.
- Use the GRADE switch in the header to preview each band.
